#  Veículos

## Sobre o projeto
Eu criei este modelo fictício de site para uma loja de seminovos com foco em geração de leads e simulação de financiamento. A ideia foi mostrar como transformar interesse em contato via WhatsApp de forma rápida e profissional.

## Funcionalidades principais
* Hero com simulador de parcelas em JavaScript com taxa ilustrativa
* Grade de veículos em destaque com CTA direto para WhatsApp
* Seção de financiamento simplificado com benefícios claros
* Formulário de venda do carro do cliente para proposta em 30 minutos
* Layout responsivo e navegação suave entre seções

## Tecnologias usadas
HTML5, CSS3, JavaScript vanilla para cálculo de parcelas e interações

## Principais aprendizados
Desenvolvendo este projeto eu aprendi a equilibrar conteúdo comercial com ferramentas úteis. O simulador aumenta o tempo de permanência e a confiança. Também entendi como estruturar CTAs contextuais sem ser invasivo e como manter a performance com código leve.
